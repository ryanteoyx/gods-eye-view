# Transcelestial intelligence prototype

An independently built commercial-research view in a fork of God’s Eye View. It deliberately starts with a 2D map and a small source-linked research set. It reuses the upstream MIT geographic-distance utility; it does not claim to be the full Cesium application or a live CRM.

## Run

Node 20 or later. No npm dependency installation or API credentials required.

```sh
cd transcelestial
npm run build
npm test
npm start
```

Open http://127.0.0.1:4173 . Stop with Ctrl-C. This directory is independent of upstream's Node/runtime requirements.

## Working features

* Natural Earth map with regional research markers, Asia/world views and source-linked detail.
* Search, region filters, saved-only view and cross-view saved records.
* Competitor developments and investor qualification profiles.
* Browser-local notes, downloadable research briefs and JSON exports.
* Optional live USGS M2.5+ earthquake refresh, visible errors and timestamps. Proximity is context, never a qualified lead.
* Source/rights ledger and an OpenBB cost and implementation roadmap.

Seed research is dated 15 October 2026. Geographic markers are approximate regional centroids. Hypotheses, reference cases and technical milestones are explicit. There are zero qualified opportunities, confirmed investor cheque sizes or implied buyer commitments. No arbitrary values are used as deal scores.

## Boundaries and next steps

Browser notes persist in localStorage for this browser and origin; there is no shared database, account login or cloud backup for notes. Export before switching devices. Hosting access control is provided by the private preview host when deployed; the standalone local server is loopback only. Do not publish a public copy with confidential content.

OpenBB, SEC ingestion, GDELT ingestion, CRM, Carta, agents and outbound communications are not connected. Next: server-side ingestion with source permissions and attribution, then team identity/storage and technical qualification, then reviewed action workflows. No scheduled background collector is created by this prototype.

The build is an allowlist. Restricted upstream data, provider proxies and settings panels are excluded. Consult THIRD_PARTY_NOTICES.md before enabling anything else. The automated tests check evidence integrity, unsafe provider payloads, stale dates, qualification limits and the deployment file allowlist.

Software and source-subscription fees in this configuration: $0. Existing hardware, internet, hosting entitlement and labour are separate. The Apache-2.0 ODP V5 licence is $0. No OpenBB installation or subscription is required to run this prototype.
